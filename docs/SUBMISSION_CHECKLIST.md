# Submission and judging — November 14, 2026 (Pacific)

Verified against the organizers' resources through the GitHub connector.

- [ ] Team ID, project title, private GitHub repo URL and contact email filled in.
- [ ] 3–10 completed tasks; omit unfinished scaffolds from the submitted task set.
- [ ] Each task has workspace manifest, instruction, human-verified reference answer,
      grading command, passing local sanity and container oracle evidence.
- [ ] Real sample agent logs included within the data terms; exports reviewed for
      credentials and restricted excerpts. Synthetic sanity is not a model run.

- [ ] By 16:30–16:45: push judged work to private repo main; confirm organizers and
      assigned judges can open the repo and essential links.

      main at that commit until judging ends. Later work belongs on another branch.
